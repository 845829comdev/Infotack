# Infotack - Security-Focused Browser

Современный браузер для специалистов в области безопасности, OSINT и пентеста.

## Особенности

- Современный и красивый интерфейс на React + Tailwind CSS
- Встроенные OSINT инструменты
- Инструменты для пентеста
- Анализ запросов и ответов
- Управление cookies и headers
- Прокси интеграция

## Требования

- Node.js 16+
- npm или yarn

## Установка

```bash
npm install
```

## Разработка

```bash
npm run dev
```

## Сборка

```bash
npm run build
```
